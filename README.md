## Descripción
TV-ApexCommerce es una aplicación para Android TV que presenta el proyecto Apex Commerce mediante una interfaz visual, moderna y navegable con control remoto.

La aplicación incluye:
- Pantalla principal con información general del proyecto.
- Beneficios principales de Apex Commerce.
- Simulador visual del proceso de compra.
- Sección de tecnologías utilizadas.
- Créditos del equipo de desarrollo.
- Navegación optimizada para Android TV mediante botones direccionales y foco visual.
- Diseño personalizado con identidad visual de Apex Commerce, logo, iconos y fondo decorativo.

## Instrucciones de ejecución
1. Abrir Android Studio.
2. Seleccionar la opción **Open**.
3. Buscar y abrir la carpeta del proyecto `TV-ApexCommerce`.
4. Esperar a que Android Studio sincronice las dependencias de Gradle.
5. Configurar un emulador de Android TV o conectar un dispositivo Android TV.
6. Seleccionar el dispositivo de destino.
7. Presionar el botón **Run ▶** para compilar e instalar la aplicación.
8. Navegar por la aplicación con las flechas del control remoto o teclado:
   - Flechas direccionales para moverse entre secciones y tarjetas.
   - Botón Enter o aceptar para seleccionar opciones.

## Requisitos

- Android Studio actualizado.
- JDK 11 o superior.
- Emulador o dispositivo con Android TV.
- SDK de Android compatible con API 36 o superior.
